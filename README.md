# 学习笔记项目

一个全面的技术学习笔记仓库，涵盖 Go 语言、算法、Git 等技术主题。

## 📁 项目结构

```
learning-notes/
├── algorithm/           # 算法学习
│   └── leetcode/        # LeetCode 题解
├── git/                 # Git 学习资料
├── go/                  # Go 语言学习
│   └── defer/           # defer讲解
└── README.md
```

## 🎯 学习模块

### Go 语言
- 延迟执行专题 (defer)
  - PPT 演示文稿
  - 示例代码
  - B站视频讲解
  - CSDN博客文章

### 算法
- LeetCode 热门题解
  - 两数之和
  - 杨辉三角
  - 相交链表
  - 反转链表
  - 回文链表

### Git
- 分布式版本控制工具学习资料

## 📌 学习建议

1. 按模块依次学习，循序渐进
2. 阅读代码示例，理解核心概念
3. 参考视频和博客，加深理解
